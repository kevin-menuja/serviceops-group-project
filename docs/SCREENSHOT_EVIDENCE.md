# Screenshot provenance — ServiceOps final group project

This repository contains **two distinct sources of visual evidence**. The README and case study now show application preview screenshots from the group's checked-in frontend; earlier screenshots extracted from the academic report remain available as historical reference. None of these images should be treated as evidence that a live production deployment was freshly tested.

## Application screenshots shown in the README

These three image files already existed within the published ServiceOps frontend source. They are application interface captures, not generated mockups.

| File used in README and case study | What the screenshot depicts | Original asset path |
